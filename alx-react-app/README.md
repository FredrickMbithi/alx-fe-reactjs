# ALX React App (Vite)

This is a minimal Vite + React starter tailored to the ALX React fundamentals tasks.

Quick start (on Kali Linux / Debian-based):

```bash
# from project root
cd alx-react-app
npm install
npm run dev
```

Open http://localhost:5173 in your browser.

Files created:

- `src/components/WelcomeMessage.jsx` — simple JSX component
- `src/components/Header.jsx`, `MainContent.jsx`, `Footer.jsx` — layout components
- `src/components/UserProfile.jsx` — demonstrates props
- `src/App.jsx` — wires components together

Kali tip: avoid using `sudo` with npm. If you get permission errors, configure npm to use a user directory for global installs.
