# Recipe Sharing App (Zustand)

A minimal React + Zustand app demonstrating state management, routing, search/filtering, editing/deleting, favorites, and simple recommendations.

## Features

- Add, edit, delete recipes (Zustand store)
- Search across recipe titles (live filtering)
- Favorites list (by recipe id)
- Mock recommendations (refresh to get suggestions)
- React Router routes: `/` and `/recipe/:id`

## Run locally

```bash
npm install
npm run dev
```

Then open the printed local URL (usually http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```
