# alx-react-app-new

Task 0 & 1 implementation: inline styled components + Counter using `useState`.

## Run

```bash
cd alx-react-app-new
npm install
npm run dev
```

Open the printed local URL.

## Components

- `Header.jsx` / `MainContent.jsx` / `Footer.jsx` inline styles
- `UserProfile.jsx` styled prop-based profile card
- `Counter.jsx` stateful counter (increment / decrement / reset)
